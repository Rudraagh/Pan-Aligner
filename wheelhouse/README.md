# Offline Python wheels

`py311/` holds the wheels for `requirements.txt` on Python 3.11, Linux x86_64 (glibc 2.17 or newer), so `scripts/hpc/pbs_setup_venv.sh` needs no network.

Copied unchanged from the canonical bundle's wheelhouse, downloaded on 2026-10-29 with `scripts/hpc/make_wheelhouse.sh` (pip 25.3). Each wheel keeps its own project's licence.
